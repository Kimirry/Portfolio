About the Developer

Building Beyond the Browser

Full-stack web development sits at the intersection of application development, databases and infrastructure. The work isn't limited to designing interfaces — it extends through the entire stack to where the application actually runs.

A strong interest in Linux and server infrastructure makes the deployment side of development just as important as the application itself. Every project is approached with the question: how does this work in production?
